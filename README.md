# Worktrack

A worksheet management application for team-based task tracking and collaboration.

## Tech Stack

- **Frontend:** ReactJS
- **Backend:** Spring Boot (see separate repository)

## Features

- Create and manage worksheets
- Track tasks and progress
- Team collaboration and task assignment

## Backend

The backend API is maintained in a separate repository. Refer to the backend repository documentation for setup and API details.
